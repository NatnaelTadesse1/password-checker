# password-checker

A simple, responsive web application that evaluates the strength of a user-provided password based on specific security criteria.

## Features
- Real-time Analysis: Checks strength as you type.
- Criteria Tracking: Checks for length, numbers, and special characters.
- Visual Feedback: Color-coded strength bars (Weak, Medium, Strong).

## How to Run
1. Clone the repository.
2. Open index.html in any modern web browser.

## Built With
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6)
